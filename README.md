# Week 10：八家公司数据优化、价值开发与结项


## 本周完成内容

1. 对八家公司和九张标准表进行覆盖诊断。
2. 为主体、投资路径、证据等级、融资日期精度和变量用途增加研究层说明。
3. 定点处理13个匿名交易主体ID，建立交易级原文参与者名册。
4. 审计69条投资路径的交易时点持股比例。
5. 回到招股书原始披露补证，使有比例路径由0提升至41条，形成27条唯一投资者—事件比例测量。
6. 对仍然缺少闭合证据的5项云汉芯城2015年B轮主体比例作正式停止决定。
7. 将32个候选变量映射到6个学术问题、6个商业问题和6个分析模块。
8. 完成八家公司描述性画像、PE/VC探索性分组比较和云汉芯城敏感性分析。

## 核心结果

- 公司：8家。
- 候选变量：32个；公司—变量记录：256条。
- 状态：VALID 215条；STRUCTURAL_NA 38条；NOT_COMPUTABLE 3条。
- 可核验融资金额公司：7家。
- 确认存在PE/VC公司：3家。
- 投资路径：69条；有交易时点比例：41条；唯一比例测量：27条。
- 确认PE/VC比例测量：16条；完整PE/VC事件案例：5个。
- 正式停止：5项；仍不可计算路径：19条。

PE/VC组在融资轮数、投资者数量和老股转让数量上呈现较高均值，但云汉芯城是强影响个案。剔除云汉芯城后，PE/VC组平均融资投资方数由7.67降至2.00，与未确认组的1.80接近；平均老股转让数由6.67降至0，低于未确认组的0.80。因此，分组结果只用于形成研究假设。

## 强制解释边界

- `null`不等于0。
- `STRUCTURAL_NA`表示结构上不适用；`NOT_COMPUTABLE`表示应有但证据不足，二者不能混用。
- 融资金额为可核验下限，必须同时报告有效样本数和金额覆盖率。
- 老股转让对价不属于发行人融资额。
- 持股比例只属于对应交易完成时点，不能跨时点加总或当作IPO前最终持股比例。
- 未确认PE/VC不等于公司没有外部机构投资。
- 八家公司只能进行样本内描述和案例开发，不进行显著性、因果性或总体代表性推断。
- 本周未引入第九家公司，因此尚未完成外部扩展性验证。
